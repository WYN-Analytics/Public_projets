# Methodologie BoutiqueFR Analytics

## Étape 1 : Compréhension du modèle de données
Analyse des schémas métier :
- client
- reference
- stock
- vente

## Étape 2 : Contrôle qualité
Mise en place de contrôles SQL pour vérifier :
- les volumes,
- les valeurs critiques manquantes,
- les anomalies financières,
- les liens entre tables.

## Étape 3 : Préparation analytique
Création de vues SQL pour simplifier les jointures et enrichir les données.

## Étape 4 : Modélisation BI
Création d’un schéma `bi` avec dimensions et faits pour Power BI.

## Étape 5 : Dashboarding
Construction d’un tableau de bord décisionnel orienté ventes, logistique et stock.
